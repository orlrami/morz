# Morz 0.0.2 — "The Bus + Additions"

**Goal:** CLIs hand work to each other automatically (kill the manual MD-file pattern), and the Workshop becomes real. Still Manual + Assisted (no full orchestration yet).
**References:** [`../MORZ-Backend-Plan.md`](../MORZ-Backend-Plan.md) §6 (bus/MCP), [`../BUILD-BREAKDOWN.md`](../BUILD-BREAKDOWN.md) (Workshop, Organizer). Freeze `docs/protocol.md` in 0.0.1; implement it here.

## Architecture (this version)

```
Main process
  MorzBus (interface)
   ├─ SQLite task board  (CAS claim: UPDATE…RETURNING WHERE status='ready'; leases + sweeper; DAG deps via NOT EXISTS)
   ├─ Named-pipe push    \\.\pipe\morz-bus-<nonce>  (NDJSON wake-notifications only; token handshake)
   └─ File mailbox        .morz/bus/ Maildir (tmp→fsync→rename→new); JSON-frontmatter+Markdown; mirrored to SQLite
  Morz MCP server host  ── each CLI spawns a thin `morz-mcp` stdio shim ─► named pipe ─► Main (all trust in Main)
  Config writer (parse+merge+backup) → .mcp.json / config.toml [mcp_servers] / opencode.json
  Catalog sync (Official MCP Registry + GitHub stars + benchmark feed) → SQLite
```

## Deliverables

### Bus v0 + auto-handoff
- **SQLite task board** first (CAS claim, claim leases + crashed-agent sweeper, DAG deps). **Named-pipe push** second. **File mailbox** only when a visible/git-diffable handoff is wanted (Obsidian-flavored markdown so `.morz/bus/` is browseable).
- **Morz MCP server** = thin stdio shim (single bundled JS, no native modules) each CLI spawns; proxies tool calls over the named pipe to Main where trust lives. Tools: `post_to_blackboard, read_blackboard, claim_task, complete_task, open_file_in_preview`. Trust boundary: agent reports arrive as MCP tool results / bus docs, **never as `user`-role messages**.
- **Handoff automation:** `post_to_blackboard(kind:'handoff')` → Main stamps sender identity → persists to target inbox → wakes it → target adapter injects a short pointer prompt. In Assisted, a **propose-then-approve chip** precedes dispatch.
- **Done / limit test:** agent A finishes → B is woken and picks up the handoff with no manual file passing; dead agent's claim is reclaimed by the sweeper; named-pipe nonce+token defeats a squatting process.

### Workshop marketplace (live)
- Ingest the **Official MCP Registry** (`registry.modelcontextprotocol.io`, incremental `?updated_since`, install-spec included) → SQLite; enrich with **GitHub stars**; benchmarks from **OpenRouter** `/api/v1/benchmarks` + `/api/v1/models`.
- Categories: Recommended / Skills / MCP servers / Plugins / Best models. **One-click Add** = the config writer above writes each selected CLI's config (parse+merge+backup, diff shown first).
- **Done / limit test:** browse real registry data with stars; Add writes a valid `.mcp.json`/`config.toml` entry and the CLI sees the server (`/mcp`).

### Organizer MCP (first-party, bundled)
- Verbs: `organizer_audit` (read-only violations), `organizer_propose` (plan of moves/renames/creates + before/after tree + hash), `organizer_explain` (cite the convention), `organizer_apply` (execute ONLY a hashed, approved plan; run-tagged; reversible; applied in a throwaway worktree first).
- **Wrap** mature tools for the heavy lifting: dependency-cruiser + Sheriff (module boundaries/cycles), syncpack (dep-version consistency); **author natively** only naming, required-files, Diátaxis docs classification, MADR ADR log, PARA/Johnny.Decimal notes rules.
- Layered rulesets: global → stack pack → project `.morz/organizer.config.ts`. Stays "assist not take over": audit/propose/explain in Assisted; apply = explicit per-plan click.
- **Done / limit test:** audit a messy vibe-coded repo → real violations; propose → reversible plan; apply in worktree → user diffs → fast-forward.

### Obsidian notes (optional — use Obsidian, no Morz vault)
- Integrate the **user's own Obsidian** (Local REST API plugin / an Obsidian MCP) — Morz does **not** ship its own vault service. Agents optionally read the vault for context + write ADRs/decisions back (scoped, no-clobber, confirm-on-delete). Local-only; private space → local model only for any summarization.
- **Done / limit test:** attach a vault → agent reads a note as context; a resolved decision writes a MADR ADR into a chosen folder visible in Obsidian.
