# Morz 0.0.4 — "Learns You"

**Goal:** Morz starts feeling like it knows how you work — a global learning memory every agent reads, plus the design-workflow browser, real routing, and a minor voice option.
**References:** [`../MORZ-Backend-Plan.md`](../MORZ-Backend-Plan.md) §4–§5, [`../research/MORZ-Round4-Research.md`](../research/MORZ-Round4-Research.md) (voice, memory, Obsidian).

---

## Deliverables

### Cross-agent LEARNING memory (the headline)
A global memory every agent reads at launch: coding standards, project conventions, "how the user likes things done" — and it **keeps learning**.
- **Model (Hermes-style, researched):** repeated corrections + durable workflow lessons become **compact memory entries or procedural skills**; writes are **staged behind write-approval** so memory never changes silently. The longer it runs, the better it knows you.
- **Storage:** local-first markdown + frontmatter (one fact / one skill per file), scoped **global / project / space / agent**, + a local FTS/embedding index (fastembed-js). Not a cloud service. Optionally back onto the user's Obsidian vault (0.0.2 integration) rather than a second store.
- **UX:** Morz surfaces "I noticed you prefer X — save this as a rule / apply it?" and injects approved memory into every agent's launch prompt. Pluggable external providers later (Honcho/mem0, the way Hermes does).
- **Done / limit test:** correct an agent twice on the same thing → Morz proposes a memory rule → once approved, a new agent in a fresh space applies it without being told.

### Browser + element-pick (design workflow)
- Embedded browser (BrowserView + `webContents.debugger` CDP), localhost auto-detect + HMR.
- **Pick element → ElementContext** (a11y ref + selector + curated styles + cropped screenshot + optional `data-morz-loc` source location). Shared loopback CDP surface so the assigned agent drives the page you watch.
- Split routing: image+styles → **Antigravity** (design critique); source-loc+HTML → the code agent (edit).
- **Done / limit test:** pick a button in a running localhost app → send to Antigravity for critique and to the builder for the edit.

### Routing
- Rules table (math → **Antigravity**, review → Codex, build → Claude) + `consult(brain, question)` MCP primitive (cross-brain one-shot, untrusted-labeled). Suggestion in Manual, card in Assisted, auto-applied-but-visible in Orchestrated.
- **Local models:** auto-detect Ollama/LM Studio; both speak native Anthropic `/v1/messages`, so route Claude local via env vars (no proxy) for cheap/private/rate-limited jobs. Classifier (fastembed) only if logs show rules missing >10% of tasks.
- **Done / limit test:** a math task auto-routes to Antigravity; a private-flagged space forces a local model; `consult()` returns a labeled cross-brain answer.

### Voice (minor)
- Default stays the CLI. Optional **local Whisper** push-to-talk dictation into the orchestrator box (like the owner's current Whisper Flow). Premium BYO OpenAI Realtime "talk-back" is a later opt-in. Low priority; confirm the exact approach when we reach it.
