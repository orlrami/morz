## Architecture (this version)

```
Renderer (React, sandboxed)  ──MessagePort(hot PTY data)──►  PTY-HOST (utilityProcess)
   Slate shell, panes, IDE pane        ◄──typed IPC(control)──►   node-pty/ConPTY, flow control,
                                                                   scrollback + ANSI-strip ring buf,
Main process                                                       block markers, MORZ_SESSION tag
   FileService (read/watch/save) · SQLite (better-sqlite3, safeStorage)
   ClaudeAdapter (stream-json) · git status reader · mode gate
```

- **PTY-host** = Electron `utilityProcess` (Node + MessagePorts straight to renderer, bypassing main for hot data). Survives window reload/close (tray-resident). Owns all PTYs.
- **Renderer** locked down: `contextIsolation:true`, `sandbox:true`, `nodeIntegration:false`, typed preload (one method per IPC msg), `setWindowOpenHandler` deny, `will-navigate` deny.
- **SQLite** in `%APPDATA%\Morz\morz.db`; scrollback blobs + logs in `%LOCALAPPDATA%\Morz`.
- **Data-dir contract** documented in the repo from this version.

## Slices & deliverables

### Slice 1 — PTY-host + real terminals
- node-pty (ConPTY, `handleFlowControl:true`, `useConptyDll`, `asarUnpack`, ABI-pinned to Electron 32), spawned in a `utilityProcess`; MessagePort channel renderer↔host.
- Two-layer flow control (node-pty XON/XOFF + ack/watermark renderer↔host).
- Panes wired into the existing Slate shell (replace the mock terminals); split-tree via dockview; pwsh 7 / cmd / WSL bash.
- **OSC-133 command blocks** — auto-inject a prompt hook (consent-gated) emitting prompt/exit marks + a Morz private OSC channel with a **per-session nonce** (anti-spoof); render as xterm marker-anchored decorations over one continuous buffer.
- **Framed-TUI mode** for interactive CLIs: raw xterm grid inside Morz chrome with the **Slate palette mapped into xterm ITheme**. Detection via a known-TUI process registry (primary) + alt-screen buffer signal.
- **Real-PATH resolution** — capture the user's login-shell env once at startup (VS Code's shellEnv pattern) so npm/pipx CLIs resolve.
- **Orphan reaping** — tag every child `MORZ_SESSION=<guid>`, Job Object per run, sweep-kill stale conhost/OpenConsole at startup.
- **Done / limit test:** pwsh + cmd + WSL + `vim` render and respond; resize storm doesn't corrupt; 50 panes; kill PTY-host from Task Manager → dead-pane UI (not white screen); **a pipx/npm-installed CLI resolves the same as in Windows Terminal (Playwright-asserted)**; no orphaned conhost after quit.

### Slice 2 — Session restore + PTY survival
- Layout tree + per-pane cwd/shell/fontSize + scrollback (`@xterm/addon-serialize`, serialize on pane-close / window-close / 30s-idle debounce — never per chunk) → SQLite; write-ahead journal.
- **PTY survival** *(owner decision: in 0.0.1)*: tray-resident PTY-host so closing the window keeps `claude`/shells alive; reopening reattaches.
- **Done / limit test:** hard-kill app → full layout+cwd+scrollback restore; close window with `claude` running → it keeps running → reopen reattaches to the live session.

### Slice 3 — Ctrl/shift-click → in-app IDE pane
- 3-tier link pipeline on `xterm.registerLinkProvider` (priority): `morz://` OSC-8 → file-path regex with `stat()`-verified existence + `file:line:col` grammar (drive-letter/`(l,c)`/WSL `wslpath` edge cases) → URLs via `strictUrlRegex`. Ctrl/Shift-gated.
- **Editable CodeMirror 6** pane "Beside": lazy languages (`@codemirror/language-data`), Slate theme driven from `tokens.css` vars, find/replace, dirty tracking, mtime **conflict banner**, **echo-suppress own saves**, **agent-rewrites-open-file → silent reload preserving scroll**.
- **FileService** in main over typed IPC: `read / save(expectedMtime) / watch` (chokidar), atomic temp-then-rename, CRLF/BOM preserved.
- `revealPosition(view,line,col)` shared by the link pipeline + `morz://open?path=&line=&col=`.
- **Open-in-VS-Code/Cursor** via `vscode://file/{path}:l:c` / `cursor://` + CLI fallback `code -g file:l:c`; registry-probe installed editors, grey out missing.
- Electron registers `morz://` scheme (`setAsDefaultProtocolClient` + single-instance lock).
- **Done / limit test:** click a tsc error path → opens at line:col; agent rewrites the open file → silent reload, scroll kept; `vscode://` opens correctly; WSL path handled.

### Slice 4 — Spaces + git
- Space = project root + optional worktree. Sidebar shows **each agent on its real branch/worktree** (owner workflow: builders on branches → merge to main), not all "main".
- Git state via `git status --porcelain=v2 --branch` in the PTY-host on a 3–5s debounce + chokidar on `.git/HEAD`/`.git/index`. No heavyweight git lib.
- **Done / limit test:** branch/dirty/ahead-behind live; worktree-per-agent listed; huge repo stays smooth; detached HEAD + rapid switches handled.

### Slice 5 — Claude Code adapter
- Spawn the user's `claude --input-format stream-json --output-format stream-json --include-partial-messages --verbose --permission-prompt-tool stdio` (+ `--resume <id>`); one ~600-line NDJSON protocol client reused as adapter.
- Parse `system/init` (capture `session_id`, `model`, `capabilities` for feature-detect), `stream_event` deltas, `assistant`/`user`, `tool_use`, `result` (cost/tokens → meters), `api_retry`. Interrupt + permissions via `control_request/can_use_tool` → Morz allow/deny dialog.
- Native React **agent-block** renderer (no terminal emulation for this lane).
- Meters: cost/tokens from `result` + local `~/.claude` JSONL (primary); `oauth/usage` endpoint best-effort with backoff; **"no data" is a first-class meter state**.
- **Done / limit test:** live lane renders; interrupt works; kill-mid-stream recovers; malformed-JSONL fuzz survives; capability detection pins a verified `claude` version range.

### Slice 6 — Mode gating (the control dial, real)
- **Manual** = adapter layer **not loaded** (plain terminals + blocks + preview + spaces only). Permanent CI gate: network-trace asserts zero LLM calls + no config writes.
- **Assisted** = one Claude lane per space; every tool permission → a Morz dialog (never auto-allow); routing/handoff **suggestion chips** (no auto-execute); no agent-to-agent.
- **Orchestrated** = disabled dial position labeled "0.0.3".
- **Done / limit test:** Manual makes zero network calls (CI); Assisted routes every permission to a dialog.

## Packaging & ops (decide/standup this version)
- electron-builder NSIS per-user + electron-updater (GitHub releases). **Unsigned for now** (personal builds; revisit signing before wider distribution — unsigned→signed breaks the updater chain).
- Crash recovery state machine: renderer-gone → reload + journal; PTY-host crash → watchdog respawn + dead-pane banner; app crash → journal restore + orphan sweep.
- Secrets (BYO API keys) via Electron `safeStorage` (DPAPI) as encrypted blobs — never plaintext, never keytar.
- Playwright `_electron` torture suite: flood, 50-pane, kill-mid-stream, malformed-JSONL fuzz, PATH-resolves test.

## Explicitly OUT of 0.0.1 (deferred, pre-specified so slices build against a frozen schema)
Message bus, orchestrated multi-agent, reviewer, commit-UX wiring, browser, remote, marketplace, memory, routing, voice. Freeze the A2A-shaped message schema (Task → Message → Part → Artifact) in `docs/protocol.md` during 0.0.1.

## Exit criteria
You use Morz as your daily terminal + mini-IDE for real work, Manual + one assisted Claude lane, and don't reach for Herdr.
