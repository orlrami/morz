# Morz 0.0.3 — "Orchestrated"

**Goal:** delegate a goal → propose plan → per-plan approval → a small real team runs, with quality gates and a daily brief. Enables the Orchestrated dial position.
**References:** [`../MORZ-Backend-Plan.md`](../MORZ-Backend-Plan.md) §2 (modes), §3 (personality), [`../BUILD-BREAKDOWN.md`](../BUILD-BREAKDOWN.md) Phase 2–3.

---

## Architecture (this version)

```
Orchestrator (planner = a CLI session the user owns, headless stream-json + Morz MCP planning tools)
  NL intent → SpawnPlan JSON (schema-validated) → editable plan card → PER-PLAN approval (hash) → Dispatcher
Dispatcher → git worktree + $PORT per agent → AgentAdapter per CLI → run-state machine (SQLite) → Job-Object kill
Reviewer loop (cross-model: non-author brain refutes) → DAG waves (DoD gate) → cost kill-switch
Daily Pulse (scheduled agent) · Bring-your-own-assistant bridge (Hermes / OpenClaw / Perplexity Comet)
```

## Deliverables

### Orchestrated v0
- Planner runs on the user's CLI headless (`claude … stream-json` or `codex exec --json`) with Morz MCP planning tools; emits a **schema-validated SpawnPlan** (never regex-parsed prose).
- **Per-plan approval** (owner decision): approve the whole team once; dispatcher only spawns from the stored hashed plan; every resource run-tagged for one-click reversibility.
- Dispatch: git **worktree + `$PORT`** per agent; `AgentAdapter` interface (`start/send/interrupt/onEvent/onPermission`) with Claude (stream-json) + Codex (`exec --json`, stdin-close fix) + Antigravity (PTY bracketed-paste). **Owner pattern:** visible pane launch — automate the `cd`→branch→launch you'd type by hand; agents shown on their branches.
- **Run-state machine** in SQLite (QUEUED→SPAWNING→RUNNING→{BLOCKED/RATE_LIMITED}→REVIEW→{DONE/FAILED/CANCELLED}); run states DRAFT→PROPOSED→APPROVED→DISPATCHING→RUNNING→MERGING→{DONE/ABORTED}). Global **Stop** kills the whole tree (Job Object).
- Plan-amendment flow: planner requests add/replace an agent mid-run → small approval card.
- **Done / limit test:** "finish X with 2 agents" → plan card → approve → 2 Claude/Codex agents run in worktrees, handoff via the 0.0.2 bus; Stop kills everything, no zombie ports.

### Quality gates
- **Cross-model reviewer** — non-author brain refutes each diff; findings as cards (apply-fix / send-to-agent).
- **DAG waves + Definition-of-Done** — a wave starts only when predecessors report **verified** done (machine checks, not self-report); handoff pulses on edges; blocked node pulses.
- **Commit UX** wired to real git (LazyGit-style staging + AI message on the staged diff).

### Cost/token kill-switch
- Hard per-run token/$ cap that pauses the team on breach. *(Revisit exact UX with owner when we reach this — owner flagged wanting detail.)*

### Bring-your-own-assistant
- Let the user connect **Hermes / OpenClaw / Perplexity Comet** as an assistant-style orchestrator that **proposes** (hosted = login/webview pane; local = spawn). Distinct from the auto fleet; maps its output to the same spawn-plan card + approval gate.

### Daily Pulse (Morz-native MCP)
- Scheduled agent (cron) reviews repo + open tasks/PRs/board → **morning brief** + in-app alarm/notification: "to close this project, do X, Y." Users can swap in Hermes/OpenClaw/Comet as the pulse engine.
- **Done / limit test:** a scheduled pulse fires, produces a brief from the real repo state, surfaces as a toast/notification.
