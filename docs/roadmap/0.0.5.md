# Morz 0.0.5 — "Your Morz"

**Goal:** Morz stops presenting every surface to every user. Features become **modules** you switch on, a first-run wizard sets up a minimal personal workspace, and the planner gets fast by default (Sonnet + GPT-5.5 race). Design direction: premium, organized, nothing "lost together".
**References:** interactive mockup (claude.ai/design project "Morz — Modular Shell & First-Run Onboarding"), w15 planner work (`w15/plan-route-optin`, `w15/planner-fast-default`), owner directive 2026-07-23.

---

## Deliverables

### Module registry + gated shell (the headline)
Every non-core surface becomes a module: one registry entry = one tab + its stores/IPC/background work.
- **Registry:** `src/shared/modules.ts` — `{ id, label, icon, defaultOn, requires?: ModuleId[] }`. Core (not listed, always on): Terminals, IDE, Spaces, Settings.
- **Defaults OFF:** Commit, Review, Orchestration bundle (Orchestrator + Waves + Runs), Browser, Organizer, Workshop, Pulse, Voice, Obsidian. **Default ON:** Sessions.
- **Gating is real, not cosmetic:** a disabled module renders no tab, mounts no component, registers no background sync, and emits no notifications. `modulesStore` (zustand, persisted in the settings DB via IPC) is the single source; `VIEWS` in Shell.tsx derives from it.
- **Autonomy interlock:** the Orchestrated dial position requires the Orchestration module; disabling the module while dial is Orchestrated drops the dial to Manual (visible notice, never silent).
- **Discoverability:** `+` at the end of the tab bar opens the module drawer; Settings → Modules is the same surface; Ctrl-K actions `module: enable/disable <name>`.
- **Done / limit test:** disable everything optional → only Terminals/IDE/Spaces/Settings tabs exist, zero orchestrator/commit/review processes or IPC traffic; enable Orchestration → Waves + Runs + Orchestrator appear without restart.

### First-run onboarding wizard
5 steps, skippable at any point ("Skip — start minimal"):
1. **Welcome** — principles: starts minimal / your own CLIs (no API keys) / reversible.
2. **Connect your CLIs** — PATH detection (claude/codex/agy/lazygit/ollama + versions), connected = available to lanes; "Get it" links for missing.
3. **Choose your modules** — core chips (locked), integration slots (below), module toggles; **live tab-bar preview** updates as you toggle (the signature element in the mockup).
4. **Autonomy** — Manual (default) / Assisted / Orchestrated (locked unless the Orchestration module is on).
5. **Ready** — summary chips + where to change it (Settings → Modules, Ctrl-K, `+`).
- Runs once (flag in settings DB); re-runnable from Settings → Modules → "Run setup again".
- **Done / limit test:** fresh install boots into the wizard; Skip yields the minimal shell; choices persist across restart and produce exactly the chosen tab set.

### Integration slots (built-in vs external tools)
A category picks ONE provider; the shell renders whichever was chosen (full provider research + integration shapes: [`../in-progress/WAVE15.md`](../in-progress/WAVE15.md) slice 4):
- **Git:** plain git in terminal (default) / **Morz Commit** / **lazygit** or **gitui** (opens in a dedicated pane, detected on PATH).
- **Review:** off (default) / **Morz Reviewer** (cross-model refutation) / **CodeRabbit** / **Greptile** / **Copilot code review** (PR-side; preference + status link only).
- **Editor:** Morz IDE slide-over (default) / **VS Code** / **Cursor** (`-g file:line` handoff).
- Slot model is generic (`{ slotId, providers[], chosen }`) so later slots (e.g. terminal multiplexer, diff viewer) reuse it.
- **Done / limit test:** choosing lazygit shows no Commit tab and `lazygit` opens in a pane; switching provider in Settings swaps surfaces without restart.

### Planner: fast by default (shipped in w15, fold into release)
- Engine `fast` = **race Claude Sonnet vs Codex GPT-5.5**, first schema-valid plan wins; default for new installs, migrated from old `claude` default.
- Claude planner model selectable: **Sonnet (default) / Opus / Fable** (`--model` flag).
- Explicit engines (claude/codex/local) remain; MORZ_E2E degrades the race deterministically to claude→codex.
- **Known gap:** the race's losing CLI process is not killed early (bounded by existing 120s timeouts) — acceptable now, revisit if cost shows up in meters.

### Design tokens stay canonical
No new theming system. `src/renderer/src/lib/tokens.ts` + brand fonts (Hanken Grotesk / Quicksand / JetBrains Mono) remain the single source; modules and the wizard consume tokens only. The wizard mockup is built purely from them as proof.

## Build order (suggested slices)
1. `w15/modules-core` — registry + modulesStore + IPC persistence + tab gating + module drawer (+ Ctrl-K actions).
2. `w15/onboarding` — wizard shell + CLI detection step + first-run flag (uses modules-core).
3. `w15/integration-slots` — slot model + git/review slots + lazygit pane launcher.
4. `w15/shell-premium` — apply the full-app redesign (separate design proposal; layout/spacing reorganization, no token changes).
